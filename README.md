NanoJev includes a simple learning system. Here's what it does in plain English:

## 📖 Troubleshooting Guide

### Problem: App won't open
- Check that you extracted a **.zip** file completely before running.
- Try right-clicking the application icon and selecting "Run as administrator."
- Restart your computer and try again.

### Problem: Download is slow
- Close other programs using the internet.
- Try downloading at a different time of day.

### Problem: Results look strange
- Make sure you have at least two candidates.
- Clear the training data (Settings → Clear Training Data) and try again.

### Problem: I see a "SmartScreen" warning
- This is normal for new apps. Click "More info" then "Run anyway." Windows will remember the choice for future runs.
